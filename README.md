## Deploy

直接将整个仓库上传到 GitHub，并开启 GitHub Pages 即可。

推荐目录结构：

```text
/
├─ index.html
├─ assets/
│  ├─ style.css
│  └─ app.js
├─ health/
│  └─ index.html
├─ links/
│  └─ index.html
├─ games/
│  └─ index.html
├─ diary/
│  └─ index.html
├─ about/
│  └─ index.html
└─ README.md
```
